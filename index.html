Налаштування
Спосіб розпізнавання, Gemini API ключі та керування даними
Апаратне — код, назву, номер зліцензії та коди звірки вводите вручну, без фото та без інтернету. Через ШІ — дані розпізнаються з фото автоматично (потрібні інтернет та API-ключ).
Заповніть один чи декілька. Активний ключ позначений зіркою — саме він використовується зараз. Натисніть «Активувати», щоб перемкнутись вручну, коли на поточному ключі закінчиться ліміт.
Отримати безкоштовно: aistudio.google.com/apikey (можна створити декілька ключів з різних Google-акаунтів). Зберігаються лише на цьому пристрої.
